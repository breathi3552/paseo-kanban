# Issue #15：GitHub Issue 导入设计讨论

本文记录截至 2026-10-16 已确认的需求与 UI/UX 约定，需求提出者已确认最后一轮分页、描述摘录、默认值及状态反馈规则。该设计已于 PR #22 落地实现，架构取舍见 [ADR-0006](../adr/0006-one-way-github-issue-import.md)，实现验证见 [Issue #15 验证记录](../verification/issue-15.md)。

## 已确认的功能边界

- 一次性单向导入，任务后续独立管理；不更新或回写 GitHub Issue。
- 每个 Paseo 项目仅从其代码目录的 `origin` 对应仓库读取，不选择其他仓库。
- 支持 GitHub.com 公开与私有仓库，复用 daemon 所在机器的 `gh` 登录态。
- 仅列出 Open Issues，由用户勾选导入。

## 已确认的界面与流程

1. 看板右上角“添加任务”按钮替换为“从 GitHub 导入”。
2. 点击后打开导入弹窗。
3. 弹窗通过项目下拉框选择项目，加载该项目仓库的 Open Issues。
4. 使用目标泳道下拉框选择导入到哪条普通泳道。
5. Issue 表格第一列为复选框，第二列主文本为 Issue 标题；下方展示 `#编号 · 作者 opened 相对时间` 等信息，实际措辞随当前界面语言变化。
6. 已导入 Issue 行仅置灰、复选框不可交互，不展示“已导入”文字。
7. 卡片只增加外链图标；手动任务不显示此按钮。点击后使用系统浏览器打开来源 Issue。
8. 导入任务详情的关联项目不可更改；项目与描述之间展示完整网址的高亮超链接。
9. 任务来源与 Issue 编号不展示为任务详情字段或卡片标签。
10. 中间列表可滚动；采用类似 GitHub 的分页，每页固定 25 条，单次最多导入 25 项；翻页清空此前勾选，不采用“加载更多”。
11. 默认由新到旧排序，表头 Issue 单元格提供排序切换按钮，支持由旧到新和由新到旧。
12. 底部左侧显示勾选计数，提交按钮只写“导入”。
13. 副文本仅展示在导入列表，不展示在任务卡片；导入时在任务描述末尾追加编号、作者及绝对创建时间的文本摘录。
14. 接受卡片外链图标放在标题行最右侧，点击仅打开网页；详情以只读项目名呈现关联项目，完整 URL 过长时换行。
15. 新功能遵循项目现有中英文 i18n，包括动态文案、错误、时间展示和可访问性提示。

## 已确认的数据规则

| 属性       | GitHub 导入任务                      | 旧任务       |
| ---------- | ------------------------------------ | ------------ |
| 任务来源   | GitHub Issue                         | 手动创建     |
| Issue 编号 | 来源 Issue 编号，用于去重            | 空           |
| 外部链接   | 来源 Issue 完整网址                  | 空           |
| 标题       | Issue 标题                           | 保持原值     |
| 描述       | Issue 正文，末尾追加来源信息文本摘录 | 保持原值     |
| 子步骤     | 初始为空                             | 保持原值     |
| 关联项目   | 固定为导入时选择的项目               | 保持现有规则 |

任务来源用于判断外链按钮是否显示。

本次仅新增已明确的任务来源、Issue 编号、外部链接三个任务属性。不另存作者、Issue 创建时间、分页、排序或列表副文本等任务字段。列表查询的临时数据与界面状态不属于任务持久属性。

导入去重检查当前看板中的任务：所选项目 ID 与 Issue 编号同时相同即为已导入。不使用链接作为去重键，不维护永久导入历史。已完成任务仍参与判定；对应任务删除后允许重新导入。

## 已确认的 UI/UX 约定

下述规则已在逐轮讨论中确认。具体像素、间距与控件样式沿用宿主和现有项目规范。

### 弹窗布局与默认值

- 顶部选择区和底部操作区固定，中间 Issue 列表独立滚动。
- 看板已筛选到有效项目时预选该项目；“全部”或“未关联”视图下显示“请选择项目”，不任意预选其他项目。
- 目标泳道默认第一条普通泳道，允许更改；不提供完成泳道选项。

### 表格与选择反馈

- Issue 主文本使用标题，不在列表内展示正文长段落。
- 副文本示例：`#42 · alice opened 2 days ago`；实际界面随当前语言呈现。
- 已导入行显示不可交互的未勾选复选框，整行不可切换选择；不增加文字或状态徽章。
- 表头提供全选当前页可导入行的复选框；支持部分选中状态。
- 底部固定显示“已选择 N 项”和“取消 / 导入”。未选项目、泳道无效、未勾选或保存中时禁用导入。

### 分页与排序

- 页脚显示上一页、有限数量的页码、下一页；窄屏缩减为上一页、当前页、下一页。每页 25 条，不增加每页条数设置。
- 以 Issue 创建时间排序，作用于整个来源仓库的 Open Issues，而非只排序当前页。
- 排序切换回到第 1 页并清空勾选；按钮提供方向图标和“最新优先 / 最早优先”的可访问名称及悬停提示。
- 切换项目回到第 1 页并清空勾选；切换目标泳道保持页码、排序和勾选。

### 操作与状态

- 切换项目清空已勾选项，切换泳道保留勾选项；晚返回的旧项目请求不覆盖新项目列表。
- 等待选择项目、加载中、无 Open Issues、加载失败分别显示明确状态；当页全部已导入时仅保留灰色列表，不新增“已导入”说明。
- 缺少仓库、没有 `origin`、非 GitHub.com、缺少 `gh`、授权或网络失败，展示对应原因及适用的重试入口，不回退到其他仓库。
- 批量导入一次保存，新任务初始未完成，按列表次序追加到目标泳道末尾。
- 保存失败保持弹窗和选择；数据版本冲突时保留仍有效的选择，重新核对已导入项与目标泳道后再提交，不静默覆盖或自动重复提交。
- 保存中锁定选择、分页、排序和提交；提交按钮保持“导入”文字，以加载指示表达进行中。
- 成功后关闭弹窗，提示导入数量；当前项目筛选会隐藏新任务时，切换到所选项目，使新任务可见。

### 国际化及副文本摘录

- 所有新增 UI 文案复用 `client/i18n.tsx` 的语言上下文与词条机制，不另建语言设置；来源 Issue 的标题、正文、作者名和 URL 不翻译。
- 列表相对时间随当前界面语言呈现；语言切换不改变当前页码、排序、勾选和目标泳道。
- 任务描述中的摘录采用导入时语言，并使用绝对创建时间而非会过期的“2 天前”；存入后作为任务正文保留，不随语言切换重新生成。
- 文本摘录采用正文后追加分隔线，再展示 Issue 编号、作者及绝对创建时间的格式，不新增任务属性。示例：

  ```text
  这里是 Issue 原始正文……

  ---
  GitHub Issue #42 · alice
  创建于 2026-10-14 10:30 +08:00
  ```

- 所有新增提示、分页控件、计数、相对时间、错误及可访问性标签均提供中英文词条。外链图标具有本地化提示，卡片不显示列表副文本。

### 状态反馈

| 场景                 | 呈现                                 |
| -------------------- | ------------------------------------ |
| 尚未选择项目         | 请选择项目以查看 Issues              |
| 正在读取             | 加载指示，暂时禁用选择和提交         |
| 没有 Open Issues     | 此仓库暂无 Open Issues               |
| 当前页全部已导入     | 保持灰色列表，计数为 0，导入按钮禁用 |
| 仓库、登录或网络错误 | 显示具体原因；可重试错误提供重试入口 |
| 保存失败             | 保持弹窗和仍有效的勾选，展示错误     |

表中为中文语义示例，实际文案通过项目 i18n 词条输出。

## 布局实施参考

以下为沿用现有界面约定的实现参考，不增加新的功能范围：

- 使用宿主 Modal；宽屏两个下拉框并排，窄屏上下排列。
- 表格复选框列固定窄宽度，其余宽度分配给标题及副文本；标题最多两行。
- 展示只读的 `owner/repo`，用于核对来源，不提供其他仓库输入入口。
- 可选行点击非独立控件区域切换勾选；已导入行整体禁用选择。
- 普通泳道的手动添加任务入口保留，本次替换右上角添加任务入口。
- 本次界面不引入搜索框；不增加未明确要求的任务字段、卡片标签或详情字段。

## 验收要点

- 项目和目标泳道选择正确生效，仅读取 `origin` 对应仓库的 Open Issues。
- 每页 25 条，单次不超过 25 项；翻页或切换排序清空勾选，全选跳过已导入项。
- 去重按项目 ID 与 Issue 编号执行；完成任务仍去重，删除任务后允许重导。
- 标题、正文、空子步骤及来源信息摘录符合映射规则，只有三个新增持久任务属性。
- 卡片只增加外链图标；详情项目只读、完整网址可点击，系统浏览器打开行为符合约定。
- 旧任务兼容，手动任务不显示外链图标，普通泳道手动添加任务可用。
- 中英文及运行中语言切换覆盖新界面；语言切换保留选择状态且不改写已存任务内容。
- 加载、空列表、全灰列表、访问失败、保存失败和并发冲突均按约定呈现。

## 技术事实与落地验证

- 开发 SDK 已升级为 `@getpaseo/plugin@0.11.4`，使用其正式导出的 `openExternalUrl` 打开系统浏览器，宿主最低版本要求设为 `>=0.11.4`。
- 自动化测试与两路独立代码审查已完成（详见 [Issue #15 验证记录](../verification/issue-15.md)）。
- 真实宿主环境下的弹窗滚动、窄屏布局、外链打开及卡片手势按 [开发指南](../development.md#5-github-issue-导入验收) 验收。
- 去重按用户指定的项目与编号执行；同一项目更换来源仓库后编号可能碰撞，此处不擅自扩展为链接或仓库维度。
