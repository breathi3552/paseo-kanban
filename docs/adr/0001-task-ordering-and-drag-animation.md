# 任务次序存储与拖拽避让动效架构

看板任务顺序采用数组原生下标表达，避让动效采用基于 React Native 原生 Animated 的弹性占位槽与平滑吸附落位方案。

## 背景

看板需要支持跨泳道拖拽、同泳道任意位置插入排序，以及拖拽过程中的动态避让和落位动效。同时系统运行在 Paseo 插件宿主环境，不可引入需要本地原生编译链接的外部第三方动效库（如 Reanimated）。

## 决策

1. **次序持久化**：采用 `board.tasks` 的隐式数组顺序表达同泳道内次序。新增 `reorderTask` 纯函数执行数组元素移动，避免增加 `order` 字段与破坏既有 Schema 兼容性。在项目筛选视图下，以相邻可见任务为基准执行相对插入。
2. **避让动效**：采用弹性占位槽（Dynamic Spacer）方案。由手势控制器根据指针垂直坐标计算插入索引，通过 React Native `Animated` 平滑展开占位槽高度，原生 Flexbox 自动完成下方卡片自然下推避让。
3. **退场与吸附**：释放时悬浮卡片通过 `Animated.spring` 平滑飞入目标占位槽矩形，动画就位后原子提交状态；取消拖拽时平滑回弹至初始位置。
4. **占位视觉与防抖**：占位槽采用等高半透明虚线轮廓框（Dashed Box）；在卡片几何中线两侧设置 12px 迟滞死区（Hysteresis Buffer），彻底规避分界线悬停抖动。
5. **视口边缘自适应**：当拖拽指针进入视口左右 48px 边缘区时，按距离渐进触发自动水平平滑滚动，保障跨屏远端泳道拖拽能力。
6. **全卡片手势分流与位移容差**：打破微小手柄限制，卡片主体全域支持手势感知。桌面端鼠标移动超过 5px 自动升级为抓起拖拽，未越过阈值松手则识别为单击打开详情；触屏端支持轻触打开、快速滑屏滚动、长按 220ms 或左侧手柄激活拖拽。
7. **手势生命周期互斥锁**：手势越过拖拽阈值后立即置位互斥锁，彻底隔离 `onPress`，落位动画结束并稳定后再安全释放，杜绝松手时的误触弹窗。
